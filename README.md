# $Whoami - Personal Portfolio

A minimal, elegant personal portfolio website built with vanilla HTML and CSS. Designed with a focus on clarity, readability, and accessibility.

## ✨ Features

- **Clean Design**: Minimalist aesthetic with a warm, neutral color palette
- **Responsive Layout**: Fully responsive design that works on mobile, tablet, and desktop
- **Fast Loading**: Zero dependencies (except Font Awesome icons) for lightning-fast performance
- **Accessible**: Semantic HTML and ARIA labels for screen readers
- **Modern Typography**: Uses Inter font family for a contemporary look
- **Social Integration**: Easy-to-access social media links with icon support

## 📁 Project Structure

```
$Whoami/
├── index.html          # Main portfolio page
├── style.css           # All styling
├── README.md          # This file
└── images/
    └── profile.png    # Profile picture
```

## 🎨 Design Highlights

- **Color Scheme**: Warm, accessible palette with excellent contrast
- **Typography**: Inter font family at optimized sizing
- **Spacing**: Consistent padding and margins for visual rhythm
- **Cards**: Subtle borders and shadows for depth
- **Hover Effects**: Smooth transitions and interactive feedback

## 📚 Sections

1. **Hero**: Introduction and quick call-to-actions
2. **About**: Personal overview and motivation
3. **Academic Background**: Education and achievements
4. **Selected Work**: Project showcase
5. **Skills**: Technical skills and competencies
6. **Connect with Me**: Social media and contact links

## 🔧 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables
- **Font Awesome**: Icon library
- **Google Fonts**: Inter typeface

## 📱 Responsive Design

The portfolio is fully responsive with breakpoints at:
- Desktop: 1120px max-width
- Tablet/Mobile: Flexible grid layouts

## 🌐 Deployment

Simply serve the files from any static hosting platform:
- GitHub Pages
- Netlify
- Vercel
- Any standard web server

## 📝 Customization

To customize this portfolio:

1. Update personal information in HTML
2. Replace `images/profile.png` with your photo
3. Modify color variables in `style.css` (`:root` section)
4. Update social media links in the "Connect with me" section
5. Add or remove skill pills as needed
